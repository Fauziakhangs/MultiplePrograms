This repository contains a collection of Java programs that demonstrate various programming concepts and algorithms. 🚀 The first program is an Insertion Sort Algorithm 📝, where we generate a list of random numbers and then use the Insertion Sort method to arrange them in ascending order. It provides a great example of sorting algorithms and demonstrates how to manipulate arrays.

Next, we have a Multiple Choice Questions ❓ program, which simulates a quiz. It allows the user to answer multiple-choice questions and checks whether their answers are correct or not. This program uses an ArrayList to store predefined answers and compare them with user inputs.

There is also a Palindrome Checker 🔄 that checks if a given string is a palindrome. This program works by reversing the string and comparing it with the original. It’s a simple example of string manipulation and logic implementation.

Another interesting program is the Prime Numbers Finder 🟢. It finds all prime numbers between a specified range. The program checks each number to see if it's divisible by any smaller numbers, and if not, it adds it to a list of primes. This is a classic example of working with loops and conditions in Java.

The Reaction Timer ⏱️ program measures how quickly a user responds after a countdown and prints their reaction time in milliseconds. Using the Thread.sleep() method and System.currentTimeMillis(), it tracks the time between the "Go" command and the user's input.

Lastly, there is a Reverse String 🔁 program that takes a string input from the user and reverses it. The string is reversed by using a char[] array, and the result is printed. The program loops, allowing the user to reverse multiple strings or quit based on their choice.
